# 创建本机点接口测试样件

本次源码贡献不提交二进制 CATPart。按以下步骤在 B30 中创建可丢弃样件：

1. 使用点模块的 CATEnv 启动单一 CATIA 实例。
2. 在 CATIA 中新建 Part，创建普通根 Geometrical Set，命名为 `DemoGeometry`。
3. 由你选择本机可写目录并手动保存为 CATPart；保持该文档激活。
4. 查看 CNEXT PID，将实际 PID、文档完整路径、`DemoGeometry`、新的点名以及
   `x_mm=10, y_mm=20, z_mm=30` 作为点接口参数。
5. 先预览，再携带返回的计划/状态/令牌明确确认创建；检查点属于目标集合，
   三个坐标长度参数驱动点，原生回读坐标为 (10,20,30) mm。
6. 按需由你手动保存；接口本身不保存或关闭文档。

重复测试使用新点名或重新创建可丢弃样件，不能重放已消费的预览令牌。
原 Clean 包中的已验收 CATPart 仍保留在本地，不随此次 PR 上传。
